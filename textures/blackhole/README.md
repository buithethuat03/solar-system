# Black-hole visualization assets

`gaia_sky.jpg` is ESA's **Gaia's sky in colour**, an all-sky map made from
Gaia DR2 measurements of the brightness and colour of nearly 1.7 billion
stars.

- Source: https://www.esa.int/ESA_Multimedia/Images/2018/04/Gaia_s_sky_in_colour2
- Credit: ESA/Gaia/DPAC
- Licence: CC BY-SA 3.0 IGO or ESA Standard Licence
- Downloaded file: 4300 x 2708 JPEG, SHA-256
  `47B0DAFF232D986251A380FE3DB87E60144C0235F3F5492C24411687D01FBD36`

The image is a display-mapped reference sky observed from the Solar System.
It is not a radiance-calibrated texture and is not presented as the exact sky
an observer at Gaia BH1 would see.

`gaia_sky_equirectangular.jpg` is the runtime derivative of that Hammer-Aitoff
source. It covers every longitude/latitude texel, so the source image's black
padding and elliptical boundary cannot be magnified into false arcs by strong
lensing. It remains in Galactic coordinates with longitude increasing to the
left and contains no synthesized stars or painted fill.

- Projection: equirectangular, 4096 x 2048
- SHA-256: `F2BA09DC29C68C479D87F212890F40EEEF95405C0AC2948248135D3A94A74965`
- Validation after JPEG encoding: zero pure-black pixels; mean/max channel
  difference across the periodic seam `0.435 / 4` on an 8-bit scale
- Generator and exact crop/edge policy:
  `tools/generate_gaia_equirectangular.ps1` and the adjacent JSON metadata

Regenerate it on Windows with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/generate_gaia_equirectangular.ps1
```

## Schwarzschild lookup

`schwarzschild-lut-512x512-rg32f.bin` is a deterministic, little-endian raw
`RG32F` table generated by `tools/generate_blackhole_lut.mjs`. Its red channel
contains the total azimuth of an escaping finite-observer null geodesic; green
is the escape mask. Captured rays are classified analytically at runtime.

The generator solves the Schwarzschild orbit equation in geometric units,
removes the turning-point square-root singularity analytically, and integrates
with 192-point Gauss-Legendre quadrature. The adjacent JSON file documents the
C1 nonlinear sampling and records checks against a 384-point CPU reference. Run:

```bash
node tools/generate_blackhole_lut.mjs
```

This solver and table were written for this project and do not contain code
from Eric Bruneton's renderer; no third-party shader code is bundled here.

## Illustrative-disk master trajectories

`schwarzschild-disk-trajectory-512x512-rg32f.bin`,
`schwarzschild-disk-families-512x1-rg32f.bin`, and
`schwarzschild-disk-observer-512x512-rg32f.bin` are deterministic `RG32F`
tables generated by `tools/generate_blackhole_disk_lut.mjs` for the opt-in
illustrative accretion disk. Schwarzschild null geodesics form a one-parameter
family in the impact parameter, so the trajectory table stores inverse radius
and its azimuthal slope along master rays (log-concentrated around the
critical curve, cubic-Hermite sampled at runtime), the family strip stores each
row's azimuth domain, and the observer table places a static observer on the
master trajectory for both captured and escaping viewing angles. The runtime
fetches these ~4 MiB only when the disk toggle is first enabled. The adjacent
`schwarzschild-disk-lut.json` records the grid contract and validation against
an independent 384-point reference integrator. Run:

```bash
node tools/generate_blackhole_disk_lut.mjs
```
